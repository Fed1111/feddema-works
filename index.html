Harvestable Ground Cover for HDRP

Painted terrain grass that finally renders in HDRP, and players can pull, cut and pick, plant by plant.

Coming soon to the Unity Asset Store.

  • One-click import of your painted terrain detail layers
  • Harvest, clear, regrow, and save what players took
  • GPU instancing with no GameObjects; memory stays flat in large worlds
  • Scatter tool, a code API for procedural worlds, and full C# source
